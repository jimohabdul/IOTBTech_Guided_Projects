# Phase 2: Application Containerization and Amazon ECR Deployment

## Objective
Containerize the ZeetaFin full-stack application (Next.js & NestJS), test locally, and push images to Amazon ECR.

## Deliverables & Structure
*   `ZeetaFin-BE/` & `ZeetaFin-FE/`: Backend and frontend application source code.
*   `Dockerfile` & `.dockerignore`: Multi-stage build instructions for containerizing the application.
*   `screenshots/`: Contains evidence of successful local container execution and ECR image pushes.
