# Phase 3: CI/CD Pipeline for Automated AWS Application Deployment

## Objective
Implement an automated GitHub Actions CI/CD workflow that builds Docker images, pushes them to ECR, and updates the deployment on AWS EC2.

## Deliverables & Structure
*   `.github/workflows/`: Contains the automated CI/CD pipeline YAML configuration.
*   `screenshots/`: Contains evidence of successful GitHub Actions workflow executions and the live application running on AWS.
